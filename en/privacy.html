Privacy Policy

World Surface

Effective date: 2026-10-03

Summary

World Surface has no accounts, no ads, no analytics and no tracking. The app does not send any data over the network. Capture, motion analysis (optical flow), face detection and 3D display all happen on your iPhone. The developer does not receive any of your data.

Camera

The back and front cameras are used to make scans. Images are only kept when they are saved to your own Photos library.

The front-camera image shows whoever is holding the phone, usually you. If you share a saved image, that part is shared too.

Face detection

Only in the Lenticular view, and only while face position is turned on, the app looks for a face in the front-camera picture to find where it is. This happens in real time on the device. No images or face data are stored or sent anywhere. The app only uses where the face is on screen; it does not try to recognize who it is.

Photos

  • The app uses add-only access to save your scans to Photos.
  • Read access is used only to show your own past scans in the app. The app looks only for scans it saved, using the photo identifiers it noted at save time, the “World Surface” album, and file names (PNG files whose names start with slitscan_). It does not load, display or send the images of any other photos.
  • The “World Surface” album is only created when you have given full Photos access.

Location

Only when location recording is turned on in Settings, and only while the app is in use, the app reads your location to record where each scan started. That location is stored in:

  • the Photos location of the saved image
  • the file name (if the option to add coordinates to the file name is on)
  • the orientation record inside the PNG

The app never sends your location anywhere.

Sharing a scan image or file also shares where it was taken. Turn off the file-name option to keep coordinates out of file names, or turn off location recording to stop recording location at all. You can also revoke location access for the app at any time in the iPhone Settings app.

Motion sensors

The gyroscope and accelerometer are used for horizon lock, for the orientation record, and for detecting tilt in the Lenticular view. The orientation record (which way the phone faced for each slit, plus how far the camera moved, measured from the video) is stored inside the saved PNG.

What the app keeps on your iPhone

  • Your settings
  • A list of the identifiers and file names of the photos it saved, so it can find them again in past scans. If coordinates are added to file names, those file names include them.

Nothing else is kept. This data stays on the device and is removed when you delete the app.

USDZ export

A USDZ file is only created when you choose to export one. It contains the scan images. If coordinates are added to file names, the USDZ file name includes them too. The file goes only where you send or save it from the share sheet.

Information shared through Apple

If you have allowed your iPhone to share analytics with app developers, Apple may pass crash reports and similar information to the developer. This is part of iOS; the app itself does not send it.

Children

The app is not specifically directed at children, and it does not collect data from anyone.

Changes to this policy

If this policy changes, this page will be updated.
